# Urbana Real Estate Portal

**Urbana** is a static real-estate portal prototype with distinct pages for property discovery, locations, amenities, gallery content, contact, and an about narrative.

## Pages

| Page | Intent |
|---|---|
| `index.html` | Entry point and property-facing landing experience |
| `properties.html` | Property exploration surface |
| `locations.html` | Location information |
| `amenities.html` | Amenity overview |
| `gallery.html` | Visual property story |
| `about.html` / `contact.html` | Brand and inquiry context |

## Local preview

Serve the repository root locally using any static web server. The source is a front-end prototype; listing availability, pricing, broker identity, lead routing, and legal disclosures require a verified backend and content source before production use.

## Production path

Before launch, add an accessible inquiry form with spam protection, real listing data, optimized image formats, performance budgets, Open Graph metadata, structured property data, legal/privacy pages, and a CI-based link check.
